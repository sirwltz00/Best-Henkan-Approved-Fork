# Henkan FE (Henkan Fan Edition)

Henkan FE is an independently maintained fan fork of the original Henkan (変換) project. It preserves the original project name and acknowledges the upstream work while using its own edition name, release packaging and project documentation.

Henkan FE is not the official Henkan project and is not affiliated with or endorsed by the original project maintainers. Please retain upstream attribution when redistributing or modifying the source. See [README.md](README.md) and [LICENSE](LICENSE).
